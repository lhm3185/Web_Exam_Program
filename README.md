# 아두이노 원격 시험

Windows PC 한 대에서 시험지를 만들고, 학생별 응시 코드를 발급하고, 답안과 점수를 확인하는 Django 프로그램입니다.

## 로컬에서 실행

PowerShell에서 저장소 폴더를 열고 실행합니다. 이미 가상환경과 관리자 계정을 만들었다면 기존 것을 사용합니다.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
```

`powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Exam.ps1`을 실행합니다. 기존에 8000번에서 개발 서버를 실행 중이면 그 터미널에서 `Ctrl+C`로 종료한 뒤 실행합니다.

- 관리자 화면은 [127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)에서 엽니다.
- 학생 화면은 [127.0.0.1:8000](http://127.0.0.1:8000/)에서 엽니다. 관리자와 별도로 테스트하려면 시크릿 창을 사용합니다.

## 시험 운영

1. **시험지**에서 제목과 제한 시간을 등록합니다.
2. **문제**에서 시험지를 골라 문항을 등록합니다. 객관식에는 보기 두 개 이상과 정답 하나가 필요합니다. 주관식과 코딩 문항에는 채점에 참고할 모범 답안을 입력할 수 있습니다. 시험지 상세 화면에서 등록한 문제와 정답을 확인합니다. 한 시험지에는 최대 30문제, 주관식과 코딩 답안에는 문제당 최대 5,000자를 입력할 수 있습니다.
3. **시험지** 목록에서 시험지를 선택하고 **선택한 시험지 공개** 작업을 실행합니다. 공개 후에도 시험지와 문제를 바로 수정할 수 있습니다. 변경 사항은 이후에 시작하는 응시에 적용되며, 이전 응시는 시작 당시의 문제와 배점으로 채점합니다.
4. **응시 코드**에서 학생과 시험지를 연결합니다. 목록과 상세 화면에서 코드를 확인해 해당 학생에게 전달합니다. 이전 버전에서 발급한 코드의 원문은 **선택한 기존 응시 코드 교체** 작업으로 새 코드를 발급해 확인할 수 있습니다. 코드를 삭제하면 해당 코드로 접속이 종료되고, 응시 기록과 답안은 보존됩니다. 서버를 옮길 때는 시험 데이터베이스와 `.access_code_key` 파일을 함께 복사합니다.
5. 학생이 **시험 시작**을 누르면 서버가 마감 시각을 기록합니다. 작성한 답안을 자동 저장하며, 같은 코드로 재접속하면 저장된 답안과 기존 마감 시각으로 이어집니다. 마감 시 서버가 마지막으로 저장한 답안으로 제출을 확정합니다.
6. **응시 기록**에서 제출 상태와 점수를 확인합니다. **답안 열기**에서 주관식과 코딩 점수, 피드백을 입력합니다. 코딩 답안은 `.ino` 파일로 받을 수 있습니다.

기존 버전에서 코드가 발급된 시험지는 객관식 문제가 정상적으로 등록되어 있으면 업그레이드 시 공개 상태로 이관됩니다. 나머지 시험지는 관리자 화면에서 공개하세요.

## ngrok 주소로 학생 접속 열기

ngrok 계정에서 인증을 마치고 [할당된 개발 도메인](https://ngrok.com/docs/domains)을 확인합니다. 아래의 `YOUR-DOMAIN.ngrok-free.dev`를 실제 도메인으로 바꿉니다.

학생 서버를 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Exam.ps1 -StudentDomain 'YOUR-DOMAIN.ngrok-free.dev'
```

다른 터미널에서 학생 서버에 HTTPS 주소를 연결합니다.

```powershell
ngrok http http://127.0.0.1:8001 --url https://YOUR-DOMAIN.ngrok-free.dev --inspect=false
```

학생에게 ngrok HTTPS 주소를 전달합니다. 8001번은 학생 화면 전용입니다. 관리자 화면은 이 PC의 8000번 주소로 사용합니다. 시험 중에는 PC와 두 서버, ngrok을 켜 두세요. 먼저 휴대폰을 모바일 데이터에 연결해 외부 주소에서 모의시험을 제출해 보세요.
